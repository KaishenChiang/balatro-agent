# Balatro Agent

[English](README.md) | 简体中文

让支持工具调用的AI通过本地MCP游玩Steam《Balatro／小丑牌》。模型负责决策，程序读取玩家可见信息、执行原生动作、确认结果，并保存和复用经验。

当前源码版本为 **1.3.2**，支持Windows x64／Steam／Codex。默认红色牌组、白注、原生随机单局；也可选择其他原版牌组、固定注级、最高注级或爬塔模式。

## 下载与开始使用

1. [下载完整项目ZIP](https://github.com/KaishenChiang/balatro-agent/archive/refs/heads/main.zip)，解压到可长期保留的目录。保留整个文件夹，EXE依赖同目录下的脚本和内置组件。准备合法安装的Steam版Balatro与已登录的Codex桌面应用，首次安装前正常关闭游戏。
2. 双击 [Balatro Agent.exe](<Balatro Agent.exe>)，等待“准备就绪”。程序自动识别自身项目目录，查找游戏、准备内置Python和固定依赖、备份并安装Mod、配置MCP；无需预装Python或手动安装组件。再次打开会核验并复用已有安装。独立安装凭证可在重新下载、移动目录或旧登记路径失效时自动恢复连接，核验后更新路径并保留其他配置。
3. 在窗口选择“牌组”和“注级／模式”，然后点击“在 Codex 中开始”。支持项目链接的Codex会打开对应项目的新聊天并填好选择与提示；启动器成功发出项目链接打开请求后自动关闭，在Codex确认并发送提示即可开始。
4. 如果项目链接无法打开，点击“复制游玩提示”，在已加载balatro-agent MCP的Codex本地聊天中粘贴发送。提示已包含实际项目路径、当前选择和完整规则，无须先手动选择项目文件夹。

首次配置后，如果Codex看不到balatro-agent工具，按客户端能力重载MCP或重新打开Codex，再发送提示。1.0.x登记的11项工具可在核验安装、关闭游戏与空闲状态后自动升级为12项；其他自定义配置冲突会保留并提示。AI先核验连接与当前游戏状态；“准备就绪”不等于已有聊天已经加载新服务。提示中的路径不会改变已有聊天的工作目录或文件权限。纯文字网页聊天无法直接操作本机游戏。

启动器按Windows显示语言默认选择中文或英文，也可随时通过“Language / 语言”切换；牌组、注级及准备状态保持，两种提示入口随界面语言切换。英文提示要求用英文报告。启动器语言不修改游戏语言；MCP使用原生控件与游戏自带本地化，读取游戏当前语言的公开文字，不依赖中文按钮名。英文操作、安装和恢复说明见[English support](docs/balatro-ai/english-support.md)。

MCP服务由Codex单独启动和管理，启动器关闭后可继续游玩。复制提示或项目链接不可用时，窗口保留供继续操作，也可在复制完成后手动关闭；完整项目文件夹仍需保留。

桌面入口统一为EXE。重复的Balatro Agent.cmd与Install.cmd已移除；需要查看安装细节、自定路径或命令行维护时，见[维护说明](docs/balatro-ai/maintenance.md)。完整包内置固定工具、Python、依赖和Mod，首次准备无需再下载这些组件；游戏本体和客户端登录由用户准备。

## 实时游玩状态

允许的新MCP启动游戏请求会同步打开独立的中英状态窗口。时间线只显示**时分秒**、阶段变化、简短决策依据、计划更新、已执行操作和心得保存结果；牌面清单、工具名、内部编号与重复查询从正文中隐藏，未确认的结果仍明确提示。当前执行进度显示在窗口上方。窗口可随时关闭，不影响游戏；相同启动编号的查询不会再次开窗。运行 `Balatro Agent.exe --monitor` 可重开，不重新准备安装。牌组／注级名称及模型提交的短双语摘要随所选语言切换；旧原文缺译文时显示本地化操作和明确提示，原文仍可查。完整记录只留本机。窗口展示模型已提交的依据和计划，无法读取未提交的内部思考。[窗口机制与实测开销](docs/balatro-ai/activity.md)说明刷新和缓存方式；[本步公开变化](docs/balatro-ai/public-changes.md)与完整观察仍向模型返回。

## 牌组与注级

启动器提供15种原版牌组。选项表示用户请求，是否解锁由AI通过游戏当前档位的公开候选核验；明确未解锁时在聊天中通知并停止。名称缺失或匿名锁定槽无法核对时如实报告无法确认，不换牌组、不降注、不强制解锁。

| 注级／模式 | 游玩方式 |
| --- | --- |
| 白、红、绿、黑、蓝、紫、橙、金注 | 使用所选等级，只尝试一局 |
| 最高注级 | 使用对应牌组当前已解锁的最高等级，只尝试一局 |
| 爬塔模式 | 从对应牌组最高已解锁注级开始；正常失败重试当前等级，获胜后核验并升一级，直到金注通关或用户叫停 |

爬塔每局先报告并复盘，再继续下一局；故障、断联和UNKNOWN保留恢复保护，不当作正常败局重开。用户请求新局时可通过原生菜单替换未完成旧局；本次目标局开始后不自行中途重开或试探存档。

## 结算与心得

每局结束返回简短报告：`实际牌组／注级｜胜负｜底注／回合｜用时｜心得更新状态`。用时包含模型决策与执行等待，起点缺失时报告未确认；心得只有成功写入并读回才称已更新，没有新认识时可保持原经验并说明原因。

单局结束或爬塔完成后，停留结算页面并保留游戏窗口。爬塔按授权在每局报告后进入下一局；只有用户另行明确要求才关闭游戏。

源码提供1份[主攻略与11个简短主题](experience/README.md)，保留61份完整修订。AI开局先实际读取主攻略，相关技巧按需读取；新心得只写本机runs/local-experience/，优先于源码基线，不自动上传或提交。用户明确要求共享时，可经来源与历史核验整理为源码基线；本次10月9日至10日的导入与原稿保留见经验索引。更新项目时保留该目录；换目录时先备份并单独迁移本地心得，详见[维护与恢复](docs/balatro-ai/maintenance.md#记录与经验)。笔记改变可读取的上下文，不改变模型参数。

1.1.0增加经验字面检索和短局内计划：AI按需找主题，保存自己写的本局方向与复查条件，局面变化时才修订。工具默认省去笔记的重复Markdown，并把较长的公开对象数组按列无损返回；原生动作确认继续保留。快速游玩通过正常菜单使用4倍速度。计划文件损坏只报告计划存储问题，不阻断MCP启动或改变游戏动作结果；历史动作查询不会回退当前观察。重连仅在公开决策点未改变时复用计划，无法确认同一局时停止复用并保留旧文件。设计、借鉴来源与验证边界见[优化说明](docs/balatro-ai/optimization.md)；实际整局提速和稳定胜率仍需实机验证。
